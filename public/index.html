📖 How to Use Panel

1

Save a User / Server Configuration

အကောင့်နှင့် ဆာဗာအချက်အလက် သိမ်းဆည်းခြင်း

On the left form, enter a nickname for the user. Select Outline or VLESS. Enter your Server's API/Panel URL. If VLESS, enter the admin username/password. Finally, enter the user's Key ID or Email and click SAVE CONFIG.

ဘယ်ဘက်ရှိ Form တွင် အသုံးပြုမည့်သူ၏ နာမည်ကိုရေးပါ။ Outline သို့မဟုတ် VLESS ကို ရွေးချယ်ပါ။ ဆာဗာ၏ URL လိပ်စာကို ထည့်ပါ။ (VLESS ဖြစ်ပါက Panel အကောင့်နှင့် စကားဝှက်ကိုပါ ထည့်ပေးရပါမည်)။ ထို့နောက် User ၏ Key ID (သို့) Email ကိုထည့်၍ SAVE CONFIG ကို နှိပ်ပါ။

2

Check Live Data Usage

Live Data အသုံးပြုမှု စစ်ဆေးခြင်း

Once saved, the user will appear as a card on the right. Simply click the 🔄 CHECK LIVE DATA button under their card. The system will securely connect to your server in the background and display their real-time used GBs.

သိမ်းဆည်းပြီးသွားပါက ညာဘက်ခြမ်းတွင် ကတ်(Card) လေးများအနေဖြင့် ပေါ်လာပါမည်။ Data အခြေအနေကို သိရှိလိုပါက 🔄 CHECK LIVE DATA ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် နောက်ကွယ်မှ ဆာဗာဆီသို့ လှမ်းချိတ်ပြီး အသုံးပြုထားသော GB ပမာဏကို ချက်ချင်း ပြသပေးပါမည်။

3

Remove / Delete User

အကောင့်များ ပြန်လည်ဖျက်ပစ်ခြင်း

If a user's subscription has expired or you no longer need to track them, you can click the small ✖ (Cross) icon at the top right corner of their card to remove them from your dashboard.

သက်တမ်းကုန်သွားသော အကောင့်များ သို့မဟုတ် ဆက်လက်စစ်ဆေးရန် မလိုတော့သော ကတ်များကို ဖျက်လိုပါက၊ ကတ်၏ ညာဘက်အပေါ်ထောင့်ရှိ ✖ (အကြက်ခြေခတ်) ခလုတ်လေးကို နှိပ်၍ အလွယ်တကူ ဖျက်ပစ်နိုင်ပါသည်။
